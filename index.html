Detrás del Algoritmo: Sistema de Recomendación Musical

Descubre cómo transformamos una encuesta de calificaciones en un motor capaz de predecir y sugerir tus próximas canciones favoritas mediante filtrado colaborativo.

Exposición del Proyecto • Desarrollado en Python con Pandas

¿Cómo sabe una plataforma qué música te va a gustar? Desliza hacia abajo para descubrir la lógica matemática y el código detrás de nuestro recomendador.

PASO 1: LA MATRIZ DE DATOS

Ingesta y Limpieza de Calificaciones

El sistema lee el archivo Musica_Encuesta_Completa.csv. El primer reto es la limpieza: eliminamos caracteres ocultos de formato (como \u200b) y transformamos las respuestas vacías o erróneas en 0 mediante pd.to_numeric(), aislando una matriz limpia de usuarios vs. canciones.

PASO 2: BÚSQUEDA FLEXIBLE

Buscador de Coincidencias Parciales

Para facilitar la experiencia de usuario, implementamos un bucle que convierte la entrada de texto a minúsculas y busca coincidencias en los títulos. Si escribes "Gaga" o "Nirvana", el algoritmo detecta automáticamente la columna exacta a procesar (ej. Smells Like Teen Spirit).

PASO 3: EL NÚCLEO ALGORÍTMICO

Segmentación de Usuarios Afines

En lugar de promediar a ciegas, el sistema busca a los usuarios que calificaron la canción elegida con un 4 o 5. Al aislar a este grupo, descubrimos qué otros gustos comparten las personas que demuestran una afinidad real por tu canción de origen.

PASO 4: MECANISMO DE CONTROL

Manejo de Excepciones (Fallback)

¿Qué pasa si una canción tiene muy pocos votos altos? El algoritmo incluye una salvaguarda (Fallback): si el grupo segmentado está vacío, utiliza el promedio general de toda la base de datos y lanza una alerta visual para evitar que el sistema falle.

PASO 5: CÁLCULO ESTADÍSTICO

Promedios, Exclusión y Top N

Calculamos la media de calificaciones del grupo selecto y aplicamos una regla crítica: .drop() para eliminar la canción de origen (¡nadie quiere que le recomienden lo que ya está escuchando!). Finalmente, ordenamos de mayor a menor para extraer el Top 3.

PASO 6: SALIDA DE RESULTADOS

La Interfaz en Consola

El resultado final despliega en pantalla un menú limpio donde expone las recomendaciones calculadas en tiempo real acompañadas de su calificación promedio estimada, garantizando una predicción basada puramente en el comportamiento colectivo.

Conclusión Técnica

Filtrado Colaborativo: El poder del criterio colectivo

Este recomendador demuestra que no necesitas analizar las frecuencias de audio ni los metadatos de una canción para saber si es buena. Entendiendo los patrones de comportamiento y los puntos de encuentro entre los usuarios de la encuesta, los datos revelan por sí solos las conexiones musicales ocultas.
