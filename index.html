Behind the scenes: Sistema de Recomendación Musical

De una encuesta a un recomendador capaz de predecir y sugerir tus próximas canciones favoritas.

Elaboración del Proyecto • Desarrollado en Python con Pandas

¿No sabes qué escuchar y quieres descubrir nueva música? Desliza hacia abajo para descubrir la lógica detrás de nuestro recomendador, podría ser la respuesta lo que buscas.

PASO 1: LA MATRIZ DE DATOS LIMPIA

Apertura de archivo csv y Limpieza de Calificaciones

El sistema lee el archivo Musica_Encuesta_Completa.csv. Para después eliminar caracteres ocultos de formato (como \u200b) y transformarlos en 0 con ayuda de pd.to_numeric(), aislando una matriz limpia de usuarios vs. canciones.

PASO 2: BÚSQUEDA FLEXIBLE

Buscador de Coincidencias

Después implementamos un loop que convierte la entrada de texto a minúsculas y busca coincidencias en los títulos. Si escribes "Gaga" o "Nirvana", el algoritmo detecta automáticamente la columna que debe de tomar (ej. Smells Like Teen Spirit).

PASO 3: CORAZÓN DEL RECOMENDADOR

Segmentación de Usuarios Afines

En lugar de promediar por promediar, el sistema busca a los usuarios que calificaron la canción elegida con un 4 o 5 y los relaciona. Al hacer esto, descubrimos qué otros gustos comparten estas personas logrando un mejor resultado para la recomendación.

PASO 4: EVASIÓN DE 0 RECOMENDACIONES

Manejo de Excepciones (Fallback)

¿Qué pasa si una canción tiene muy pocos votos altos? El programa usa la función de (Fallback): si el grupo segmentado está vacío, utiliza el promedio general de toda la base de datos y da otra recomendación la cual puede no ser tan acertada, pero a partir de ahí podemos recomendar más.

PASO 5: CÁLCULOS

Promedios, Exclusión y Top N

Calculamos la media de calificaciones del grupo y aplicamos .drop() para eliminar la canción de origen (no queremos que se recomiende la que ya te gustó). Finalmente, ordenamos de mayor a menor para extraer el Top 3.

PASO 6: PRINTING DE RESULTADOS

UI

Finalmente el usuario ve en pantalla un menú limpio donde están las recomendaciones calculadas en tiempo real acompañadas de su calificación promedio estimada, brindando una predicción basada puramente en el comportamiento colectivo.

Conclusión

El poder del criterio colectivo y cómo nos afecta

Este recomendador demuestra que no necesitas analizar las frecuencias de audio ni los metadatos de una canción para saber si es buena. Entender los patrones de comportamiento de las personas y los puntos de encuentro entre los usuarios de la encuesta, los datos revelan por sí solos las conexiones musicales ocultas. Estos resultados también demuestran que sí existe una alta probabilidad de que los sistemas de recomendación puedan ser manipulados para favorecer a ciertos géneros o artistas.
